# Luau-библиотеки проекта

Инвентарь существующих модулей и границы браузерного API. Пути считаются от `public/`, если не указано иное.

## Запуск и сервисы

| Модуль | Назначение | Использование |
|---|---|---|
| `main.luau` | Точка входа: подключает UI-компоненты и страницы, запускает core и выбирает страницу по `Client.PagePath`. | Загружается JS-загрузчиком Luau. |
| `LocalizationService.luau` | Таблица переводов и `Get(name)`, выбирающий строку по `Client.Language`; при отсутствии языка использует английский. | `require("LocalizationService").Get(key)` |
| `table.luau` | Вспомогательные операции: поверхностное и глубокое копирование, объединение двух таблиц и подсчёт ключей. Стандартная глобальная библиотека Luau `table` не заменяется. | `local Table = require("table")`; `ShallowCopy`, `DeepCopy`, `Merge`, `Count` |

## UI-компоненты

| Модуль | Назначение | Входные данные / результат |
|---|---|---|
| `UI/Text.luau` | Создаёт `TextLabel` с цветом, шрифтом, размером и текстом. | `text` обязателен; остальные поля опциональны; возвращает Instance. |
| `UI/TextButton.luau` | Создаёт кнопку, подключает click callback, скругление, отступы и hover-tween. | `text` обязателен; `onClick` должен быть функцией; возвращает Instance. |
| `UI/Container.luau` | Создаёт `Frame` либо `ImageLabel`, применяет свойства, добавляет `UIListLayout` и переданных детей. | `children` и `parentTo`; `containerProps`, `listProps`, `type` опциональны. |

## Страницы

| Модуль | Назначение |
|---|---|
| `pages/corePage.luau` | Общая часть интерфейса, запускаемая всегда. |
| `pages/main.luau` | Содержимое главной страницы. |
| `pages/404.luau` | Страница неизвестного маршрута. |

## Контракт JavaScript-моста

`src/main.js` создаёт Luau-среду, регистрирует глобальные функции и загружает Luau-модули. `src/instance.js` реализует дерево Instance, свойства, события, layout и DOM-отрисовку. `src/tween.js` реализует TweenService и меняет свойства через Instance-мост. `Instance.new(className, props, children)` принимает таблицу свойств вторым аргументом и массив детей третьим; присваивание `Parent` остаётся поддерживаемым. Эта React-Lua-подобная форма является частью публичного контракта.

### Доступный поднабор API

Реализованные классы Instance: `ScreenGui`, `Frame`, `ScrollingFrame`, `TextLabel`, `TextButton`, `ImageLabel`, `ImageButton`, `UICorner`, `UIStroke`, `UIListLayout`, `UIPadding`. Сигналы UI: `MouseButton1Click`, `MouseEnter`, `MouseLeave`. В окружении также есть `UDim`, `UDim2`, `Vector2`, `Color3`, `Enum`, `TweenInfo`, `TweenService`, `Client` и `game:GetService` для реализованных сервисов.

Это браузерная совместимая реализация, а не полный Roblox API. Свойства и Enum поддерживаются только в объёме, реализованном в `src/instance.js` и `src/main.js`; Roblox-совместимость не подразумевается.

## Правила добавления библиотек

- Переиспользуемые компоненты размещаются в `UI/`, страницы — в `pages/`, сервисы и таблицы данных — в корне `public/`.
- Компонент получает один props-table, задаёт разумные значения по умолчанию и возвращает созданный Instance.
- UI-компонент не выбирает маршрут и не загружает страницу; маршрутизация остаётся в `main.luau`.
- Новые библиотеки документируются здесь вместе с назначением и публичными входами.
